## Visão Geral

O **MangaCut Studio** é uma ferramenta de edição de imagens para mangá e animação, com foco em:

- **Transformações geométricas:** rotação, escalonamento, espelhamento e distorção de camadas.
- **Segmentação de anime:** integração com modelos ISNet via ONNX Runtime para isolamento de personagens e fundos.
- **Processamento PSD:** leitura e escrita de arquivos Photoshop (.psd) com suporte a múltiplas camadas e grupos.
